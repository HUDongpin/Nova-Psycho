# Bundled Noto CJK fonts

Official source: https://github.com/notofonts/noto-cjk/tree/f8d157532fbfaeda587e826d4cd5b21a49186f7c

Pinned upstream commit: `f8d157532fbfaeda587e826d4cd5b21a49186f7c`. Retrieved 2026-10-08.

The unmodified Regular OpenType fonts provide Simplified Chinese (SC) and Traditional Chinese Hong Kong (HK) glyph variants for PDF rendering. They are licensed under SIL Open Font License 1.1; see OFL.txt. Font copyright notices are retained inside the original font files.

These files are private deployment assets, outside public/. The PDF renderer reads them locally; it never downloads fonts at runtime.
